PSA Cockpit

EMs de ProServe LATAM · Instalación en 10 minutos, una sola vez

1Pide acceso

Pídele a Jair García que te agregue como colaborador del repo privado PSA_Cockpit_Data y que te comparta la contraseña del cockpit. Te llega una invitación de GitHub: acéptala.

2Instala Tampermonkey

Es la extensión que pone el botón dentro de Salesforce. En Chrome: Instalar Tampermonkey

Importante: abre chrome://extensions, entra a Detalles de Tampermonkey y activa «Allow User Scripts» («Permitir scripts de usuario»). Sin esto el botón no aparece. Luego recarga Salesforce.

3Instala el script

Un clic. Tampermonkey abre una pantalla con el botón «Instalar».
Instalar PSA Cockpit

Se actualiza solo cuando sale una versión nueva.

4Crea tu token de GitHub

  1. Abre github.com → Fine-grained token.
  2. Nombre: PSA Cockpit. Expiración: 90 días.
  3. Resource owner: AWSEMJairGarcia. Repository access: «Only select repositories» → PSA_Cockpit_Data.
  4. Permissions → Contents: Read and write. Nada más.
  5. Genera el token y cópialo.

El token se guarda solo en tu navegador. No lo pegues en correos ni chats.

5Pega el token

Abre cualquier proyecto en ProServe CRM. Abajo a la derecha aparece el botón naranja PSA Cockpit. Dale clic derecho, pega el token y acepta.

6Úsalo cada viernes

  1. En la página del proyecto: clic en PSA Cockpit. Lee el encabezado y los reportes, y los sube. Tarda 1 a 2 minutos.
  2. En el Project Planner del proyecto: pon Included dates del inicio al cierre y da clic en PSA Planner.
  3. Abre el cockpit unos 2 minutos después y entra con la contraseña.

Todo es de solo lectura: el script no modifica nada en Salesforce. Los datos van a un repo privado y el sitio solo muestra páginas cifradas.
